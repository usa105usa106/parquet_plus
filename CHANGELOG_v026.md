# v026

- Gmail anti-duplicate усилен без изменения порядка Telegram → Gmail: автоматический повтор `send` остаётся только для гарантированно предзапросных connect/DNS/connect-timeout ошибок и для явного `429`.
- HTTP `408`, любые `5xx`, read-timeout/server disconnect и другие неоднозначные ошибки после начала Gmail POST теперь **не повторяются**: бот возвращает `GmailSendUncertain`, чтобы не создать второе письмо, если первое уже было принято Gmail.
- `401` по-прежнему делает один refresh access token; постоянные `4xx` не повторяются; deterministic `Message-ID` и persistent ledger сохранены.
- В ручном `/binance ...` поле `change_7d_pct` теперь рассчитывается из уже скачанных закрытых Binance Spot `1D` свечей (последний закрытый close против close семь дневных интервалов назад). Поэтому 7d-поля `market_breadth.parquet` больше не пустые при наличии минимум 8 дневных свечей.
- Исправлена точность `/status`: время и длительность «Последний parquet» обновляются только если ZIP действительно был успешно собран. Ошибка сборки больше не подменяет время предыдущего успешного Parquet.
- Остальная логика не изменялась: Анализ, основной top-100/150/200/250/300, candidate pool 500/1000, MEXC/XAU/XAG/USOIL, ручные команды, Telegram delivery, очистка ZIP и формат архивов сохранены.
- Версия обновлена везде до `v026`.
