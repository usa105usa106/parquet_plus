# Coolify Trading + Market Data Bot v005

Бесплатный Telegram-бот без OpenAI API. Есть два независимых режима: **Анализ** — бот сам делает свежий рыночный анализ и выдаёт компактный финальный вердикт; **Parquet** — бот не выбирает LONG/SHORT, а только собирает свежие сырые данные, отправляет ZIP в Telegram и затем те же байты в Gmail как `.zip.jpg` для анализа в другой среде ChatGPT.

Никакого candle cache: каждый запуск получает данные заново.

## Кнопки

```text
[ Анализ ]   [ Время выкл ]
[ Parquet ]  [ Почта ]
[ Пинг ]
```

- **Анализ** — то же, что `1` или `/scan`; бот сам делает анализ.
- **Время ...** — `выкл → 15 мин → 30 мин → 1 час → 4 часа → выкл`.
- **Parquet** — то же, что `/parquet`; только сбор данных, без выбора LONG/SHORT.
- **Почта** — то же, что `/gmail`.
- **Пинг** — версия, Telegram latency, uptime, RSS-память.

Старые текстовые названия `Отправить parquet` и `Подключить почту` также принимаются как совместимые алиасы, но на клавиатуре больше не показываются.

### Как работает «Время»

Выбор интервала сам ничего не запускает. После выбора нажмите **Анализ** или **Parquet**. Бот будет циклически повторять именно выбранное действие. Новый интервал отсчитывается после полного завершения предыдущего запуска. Ручное нажатие другого действия переключает автодействие на него. При `Время выкл` действие выполняется один раз.

## Анализ

Локальный алгоритм без LLM/API использует Binance Spot для крипто-техники и ликвидности, MEXC Futures как источник funding и бесплатные публичные источники для market/macro context. Результат — только `ФИНАЛЬНЫЙ ВЕРДИКТ · v005`.

## Parquet

### Crypto

Бот формирует 100 наиболее капитализированных non-stable/non-wrapped активов, для которых есть активная Binance Spot `USDT` пара. По каждому загружается до **999 полностью закрытых 1H свечей**. Текущая незакрытая 1H-свеча исключена. В Parquet сохраняются OHLC, base/quote volume, число сделок и taker-buy volume.

### MEXC funding

Для каждого из 100 криптоактивов бот пытается найти соответствующий MEXC Futures perpetual. Сохраняются current funding и последние 30 funding settlements. Если контракта нет — `NOT_ON_MEXC`. Binance Futures не используется.

### XAU / XAG / USOIL

MEXC Futures: `XAU_USDT`, `SILVER_USDT`, `USOIL_USDT`, до 999 полностью закрытых 1H-свечей на инструмент.

## Состав ZIP

```text
market_scan_YYYYMMDD_HHMMSS.zip
├── crypto_ohlcv.parquet
├── commodities_ohlcv.parquet
├── funding_mexc.parquet
├── universe.parquet
├── PROMPT_FOR_CHATGPT.txt
├── manifest.json
└── status.json
```

`PROMPT_FOR_CHATGPT.txt` содержит полный мастер-промпт. Он прямо сообщает, что бот только собрал данные и не выбирал кандидатов, требует построить 4H/1D из 1H, проверить свежий внешний контекст и пользователю вывести только компактный `ФИНАЛЬНЫЙ ВЕРДИКТ`, без промежуточной болтовни.

## Telegram → Gmail

Для **Parquet** порядок строгий:

1. Telegram получает `market_scan_....zip` без `.jpg`.
2. После этого Gmail получает точно те же ZIP-байты с именем `market_scan_....zip.jpg` и MIME `image/jpeg`.

Для распаковки почтового вложения удаляется только последний `.jpg`. Перед Gmail-отправкой бот повторно проверяет размер и SHA-256 и использует ledger защиты от дублей.

## Почта / Gmail OAuth

Почтовая реализация основана на проверенной Gmail OAuth-схеме: callback через публичный HTTPS Coolify, Google OAuth `gmail.send`, зашифрованное хранение Client ID/Secret и refresh token, тестовое письмо и защита от повторной отправки.

Нажмите **Почта**. Далее весь ввод Google Client ID/Secret и подключение аккаунта происходит через Telegram. Секретные сообщения бот удаляет.

## Coolify

Для обычного развертывания вручную задаётся только:

```env
TELEGRAM_BOT_TOKEN=...
```

`compose.yaml` использует magic variable `SERVICE_URL_GMAILAUTH_80`, поэтому публичный Gmail callback создаётся Coolify автоматически и ведёт на container port 80. Остальные значения уже имеют встроенные настройки. Persistent volumes сохраняют состояние и Gmail OAuth между redeploy/restart.

Подробно: `COOLIFY.md`.

## Status

`/status` показывает v005, текущее действие, таймер и следующее выполнение, статистику самостоятельного анализа, последний Parquet, размер ZIP, покрытие Binance Spot/MEXC funding/XAU-XAG-USOIL, Gmail status и память процесса.
