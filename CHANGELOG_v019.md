# v019

- Локальный финальный вердикт Telegram переведён на HTML-разметку: `LONG`, `SHORT`, тикер выбранного актива, все числовые значения в торговом блоке и `NO TRADE` отображаются жирным.
- После тикера выбранного актива добавлена актуальная цена на момент сканирования: для крипто — `lastPrice` Binance Spot, для XAU/XAG/USOIL — `lastPrice` MEXC Futures из уже используемого общего ticker-запроса.
- Форматирование цены больше никогда не использует scientific notation (`E...`). Для дешёвых монет автоматически увеличивается число знаков после запятой; лишние хвостовые нули удаляются (`0.010000 -> 0.01`, `1.050000 -> 1.05`).
- Сырьевой `/score_s`, `/help`, подробные commodity score в `/log_full`, 24-часовой diagnostic log и next-week calendar сохранены без изменения поведения.
- `/log_full` по-прежнему содержит только последние 24 часа; файловый лог делится на часовые сегменты и хранит 24 ротации.
- Parquet collector не изменён byte-for-byte; Gmail delivery и timer logic не менялись.
- Версия обновлена на `v019` в runtime-коде, Docker metadata, документации, prompt и self-test файлах.
