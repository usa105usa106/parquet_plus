# v005

- Кнопка **«Отправить parquet»** переименована в **«Parquet»**. Логика `/parquet` не менялась.
- Кнопка **«Подключить почту»** переименована в **«Почта»**. Логика `/gmail` не менялась.
- Старые текстовые названия сохранены как скрытые совместимые алиасы: если вручную отправить `Отправить parquet` или `Подключить почту`, команды по-прежнему сработают.
- Клавиатура: `Анализ | Время`, `Parquet | Почта`, `Пинг`.
- Режим **Время** по-прежнему циклически повторяет последнее выбранное действие: `Анализ` либо `Parquet`.
- Telegram получает Parquet-архив как обычный `.zip`; Gmail — те же ZIP-байты как `.zip.jpg`.
- Docker Compose упрощён для Coolify: единственная пользовательская environment variable — `TELEGRAM_BOT_TOKEN`. Публичный Gmail callback создаётся magic variable `SERVICE_URL_GMAILAUTH_80`, остальные настройки имеют встроенные значения по умолчанию.
- Версия изменена во всех текущих компонентах на **v005**.
