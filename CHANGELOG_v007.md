# v007

- Версия изменена по проекту на **v007**.
- Исправлен сценарий кнопки **Почта**: теперь при отсутствии Gmail она **сразу** просит Base64-строку экспорта старой авторизации.
- Полностью убран пользовательский Google OAuth/callback-flow из Telegram-интерфейса. Старые inline-кнопки `gmail_check`, `gmail_config`, `gmail_login`, `gmail_oauth_setup` блокируются и предлагают нажать обычную кнопку **Почта**.
- Импортированная Gmail-сессия хранится только в памяти процесса и исчезает после redeploy/restart.
- Сообщение с Base64-строкой удаляется до обработки. Содержимое строки не логируется.
- `/log_full` сохраняет и отдаёт журнал операций. OAuth access/refresh tokens, Client Secret, Telegram bot token, Fernet key/token, API secrets и длинные Base64-последовательности редактируются/не логируются.
- В сообщениях Gmail import указана версия v007, чтобы сразу видеть, что Coolify действительно запустил новый код.
